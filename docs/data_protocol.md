# German Credit 数据与预处理协议

关联任务：[成员 1 / Issue #1](https://github.com/cohesivepuma/missing-aware-credit-risk/issues/1)。本文定义供缺失机制、模型和校准模块复用的数据边界；代码实现和团队评审以该 Issue 对应 PR 为准。

## 可用于课程报告的正文

本研究选取 UCI Machine Learning Repository 发布的 Statlog German Credit 数据作为个人信用风险分类实验数据。数据来源与引用为 Hofmann（1994），数据集 DOI 为 [10.24432/C5NC77](https://doi.org/10.24432/C5NC77)。本项目使用保留原始字段的 german.data 文件，通过官方来源下载、固定 SHA256 校验及转换脚本保证输入可追溯。

数据包含 1000 条记录和 20 个信用相关字段，其中 7 个字段按数值处理，13 个字段按类别处理。检查结果为无 NaN、无缺失标签、无完整重复记录、无重复特征记录。原始标签中的 Good（1）和 Bad（2）分别映射为 0 和 1，样本数分别为 700 和 300。标签含义为 Good/Bad 信用类别，本实验不将其解释为特定期限内的违约事件。目标列与行索引均不作为模型输入。

预处理过程保留文件中的行顺序，为每条记录建立零基行索引。使用 seed=42 的分层抽样，将数据划分为 600 条训练数据、200 条验证数据和 200 条测试数据；验证数据进一步分为互斥的 100 条调参/早停数据与 100 条校准数据。基础模型及预处理只使用训练数据拟合，调参/早停数据用于模型选择，校准数据在基础模型冻结后使用，测试数据用于最终指标报告。所有模型共享保存的行索引划分，读取时检查数据指纹和配置。

为了同时支持数值矩阵接口与原始字段级缺失实验，类别字段按预先定义的官方枚举转换为固定数值代码。这些代码仅作为类别载体，不表示连续大小关系，也不通过全数据拟合。Logistic Regression 内部对数值字段进行训练集中位数填充与标准化，对类别字段进行训练集众数填充与 one-hot 编码。测试中新出现的类别不加入编码器的训练类别集合。原始数据无 NaN，但显式“未知/无账户”等类别保留为可观测类别，不被自动转换为实验缺失。

输入数据统一表示为 {x, mask, y}，其中 mask 与原始字段矩阵同形，1 表示 observed，0 表示 missing。后续缺失实验在划分后、填充与 one-hot 编码前操作原始字段，并保留原始 mask；类别扩展后的不同 one-hot 列不作为独立缺失单位。这保证模型之间能够共享相同缺失情形，并使 Mask-aware 模型使用原始字段的缺失信息。

## 对接约定

- **成员 2**：缺失作用于原始字段的 x 列，更新同形 mask；原始标签和行顺序不变。类别载体不能未经说明作为连续 MAR/MNAR 驱动量；根据类型使用类别条件或数值关系，MAR 驱动字段保持可观测。
- **成员 3**：通过 configs/german_credit.yaml 使用共享行索引；其他传统模型明确自己的类别处理策略。更换种子时同步更改 manifest_path，不能复用不匹配的索引文件。
- **成员 4**：外部仍接收原始 x 与同形 mask；内部编码后的 x 可与原始 20 维 mask 拼接，原始 mask 不因填充而改成 1。早停仅使用 validation_tune。
- **成员 5**：仅使用 validation_calibration 拟合校准；冻结基础模型，不根据测试结果选择校准方法或阈值。

未来机制、缺失率或模型更改不应改写当前共享协议；确有需要时通过单独 PR 同步配置、元数据和相关测试。
