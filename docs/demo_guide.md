# German Credit 交互演示

启动 `./scripts/run_demo.sh`，打开 <http://127.0.0.1:8501>。这个旧版演示围绕 German Credit 的 Good / Bad 分类，包含研究总览、交互预测和缺失实验室三个页面。新前后端工作台位于 <http://127.0.0.1:8000>，启动方式见 [产品演示指南](platform_guide.md)。

1. **研究总览**：介绍 1,000 个样本，以及独立的训练、调参保留、校准与测试样本。说明模型的区分能力与概率可靠性是两个问题。
2. **交互预测**：选择样本并隐藏贷款金额或年龄，查看完整输入、缺失输入和校准后的概率。改变字段后，结果是一个新的假设输入，不再沿用原记录的真实标签。
3. **改变场景**：切换 MCAR / MAR / MNAR、缺失比例、随机种子与模型。目标字段缺失 30% 不能称为全表缺失 30%；页面会显示全表实际缺失率。
4. **缺失实验室**：查看可靠性曲线、每个分箱的样本量及校准前后指标。校准可能改善也可能退化；跨种子标准差不是置信区间。

类别输入沿用 UCI 原始编码，避免将数值载体误解成连续量。首次准备数据需要联网，之后本地演示可以离线运行。
